# Run NPM Watch Mode

Start `npm run start` (watch mode) on all 4 packages in parallel:

1. Run `npm run start` in parallel in these directories:
   - `wp-content/themes/BBJ`
   - `wp-content/plugins/bbj-v2`
   - `wp-content/plugins/bbj-tools`
   - `wp-content/plugins/bigbrotherjunkies-data`

2. Run all 4 commands in the background so they can watch simultaneously

3. Let me know when all watchers are started and how to stop them

Note: These are long-running watch processes that will rebuild on file changes.
