# Create New Feature Branch

Create a new feature branch from staging:

1. Fetch latest from origin
2. Switch to staging branch
3. Pull latest staging changes
4. Create new branch named `feature/$ARGUMENTS` (use the argument I provide as the branch name)
5. Confirm the new branch was created and I'm on it

If no argument is provided, ask me what to name the feature branch.

Example: `/new-feature chat-system` creates `feature/chat-system`
